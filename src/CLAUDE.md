# CLAUDE.md — Epsilon

An arbitrary-precision arithmetic library for **computable real numbers**, built in **C++23**. See `.ai/architecture.md` for the full architecture document.

## Build & Test

```bash
# Configure (from src/)
cmake -B b -S .
# Build
cmake --build b
# Test
cd b && ctest --output-on-failure
```

For a clean reconfigure: delete `b/CMakeCache.txt` and `b/CMakeFiles/`, then reconfigure.

## Project Layout

```
src/
├── epsilon/          # Header-only math library (INTERFACE, no compiled sources)
│   ├── t.hpp         #   Core types: z<C>, sign, container concept, digit aliases, errors
│   ├── z.hpp         #   Big integer arithmetic (add, sub, mul, div, pow, root, shifts)
│   ├── r.hpp         #   Lazy real numbers via coroutines + elementary functions
│   ├── coro.hpp      #   Custom lazy<T> coroutine for R-number approximations
│   ├── ops.hpp       #   Operator overloads (+, -, *, /, %) for z<C>
│   ├── chars.hpp     #   String conversion (from_chars, to_string)
│   └── tmp.hpp       #   Overloads pattern (variant visitor helper)
├── engine/           # Static library — math expression parser
│   ├── lexer.*       #   Text → tokens (integer/real literals, ids, operators, parens)
│   ├── parser.*      #   Recursive-descent parser → AST (binop, func_call, paren_expr, val_term)
│   ├── utils.*       #   AST dump/pretty-print
│   └── tmp.hpp       #   Overloads pattern (duplicated from epsilon)
└── ut/               # Unit tests (GoogleTest 1.17.0 via FetchContent)
    ├── def.hpp       #   Shared test type aliases (sz, mz, lz)
    ├── *_tests.cpp   #   One file per module under test
    └── CMakeLists.txt
```

## Module Rules

- **`epsilon`** is header-only, C++23, no external deps. All public APIs in `namespace epx`.
- **`engine`** is a static lib (`epsilon_engine`), links `epsilon`. Namespace: `epx::script`.
- **`ut`** links both libraries + GTest. Namespace: `epxut`.
- AST nodes in `engine` are allocated from `std::pmr::monotonic_buffer_resource` (arena) — do NOT `delete` them individually; they live as long as the owning `mathscript`.

## Conventions

### Naming
- `snake_case` for everything: types, functions, enums, files, namespaces.
- Template params: single uppercase — `C` container, `D` digit, `T`/`U` generic, `B` base, `F` callable.
- Private members: trailing underscore (`input_`, `cursor_`, `state_`).
- Error types: `snake_case_error`, inherit `std::runtime_error`.
- Unsigned magnitude functions: `_n` suffix (`add_n`, `cmp_n`); signed wrappers drop it.
- Enum values: `snake_case` in `enum struct` (`token_ec::bad_input`).

### Types & Construction
- Prefer `struct` over `class`, even with private members.
- `explicit` on single-arg constructors. Delete copy, define move for owned resources.
- Designated initializers everywhere: `z<C>{.digits = {1}, .sgn = sign::negative}`.
- Multi-return via local `result_t` struct: `return {.q = ..., .r = ...}`.
- `using D = typename z<C>::digit_type;` for local type aliases.

### Error Handling
- `std::expected<T, E>` as primary error path (lexer, parser). Chain with `.and_then()`, `.transform()`, `.or_else()`.
- Exceptions only for fatal arithmetic violations, marked `[[unlikely]]`.
- `assert()` for internal invariants. `std::terminate()` for unreachable paths.

### Control Flow
- Structured bindings: `auto [q, r] = div_n(u, v);`.
- `for (;;)` for loops with internal break (Newton, series convergence).
- `std::exchange` for move-and-reset: `coro_(std::exchange(rhs.coro_, {}))`.
- `if constexpr` for compile-time branching on template params.

### Templates & Constexpr
- `constexpr` everywhere possible. `noexcept` consistently.
- Concepts for constraints: `template <container C>`.
- Free functions over members: `is_zero(num)`, not `num.is_zero()`.
- `static_assert` for compile-time invariants.

### Includes & Namespaces
- Group includes with labels: `// std`, `// epx`, `// ut` — in that order, blank lines between groups.
- `namespace epx` (core), `epx::script` (engine), `epx::coro`, `epx::tmp`. Tests: `epxut`.
- Internal impl in anonymous `namespace { ... }` inside `.cpp`.
- Close multi-line namespaces: `}  // namespace epx`.

### Tests
- `TEST(SuiteName, snake_case_name)`. Test across `sz`/`mz`/`lz` to cover digit sizes.
- `constexpr auto verify = [](...) { ... };` for repetitive checks.
- Use `stosz(s)` / `stomz(s)` / `stolz(s)` from `def.hpp`.

### Comments
- Only `//` for critical cases (design decisions, workarounds, non-obvious constraints). No block/doc/redundant comments.
- `// todo: ...` for future work. `// Generated by AI ...` on AI-assisted sections.
- SPDX header on every file: `// SPDX-License-Identifier: MIT` + copyright line.

### Misc
- Include guards: `#ifndef EPSILON_INC_Z_HPP` / `#define` / `#endif`.
- `std::variant` dispatch via `std::visit` + `overloads` (defined in `tmp.hpp`).
- `r<C>` is base-4: approximations return `floor(x * 4^n)`. Precision guards (`exp_guard=12`, etc.).
- `z'123` = integer literal, `r'3.14` or `3.14` = real literal.
- Parser: 1-token lookahead (`curtk` + `nextk`). AST nodes arena-allocated via `pmr::monotonic_buffer_resource` — never `delete`.

## Current Limitations

- No math expression **evaluator** yet — the parser produces ASTs but they can't be executed.
- `max_digit_type` is `uint32_t` — 64-bit digit types (`lz` in tests) work but aren't the default.
- Base-10 only for string conversion (other bases are marked `static_assert("not implemented")`).
- Single-statement parsing only (`// todo: support multiple statements`).
